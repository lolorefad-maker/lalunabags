# LALUNA — Timeless Luxury Handbags

متجر حقائب فاخرة بتصميم تحريري كلاسيكي وعصري (Editorial Luxury Handbag Boutique).

## Features | المميزات
- **Luxury Editorial Design**: مستوحى من دور الأزياء العالمية الكبرى بتصميم راقٍ وخامات مميزة.
- **Mobile Responsive**: متجاوب بالكامل مع كافة مقاسات الشاشات والهواتف الذكية.
- **Bilingual (AR / EN)**: دعم كامل للغتين العربية والإنجليزية مع ضبط اتجاه النصوص (RTL / LTR).
- **Interactive Bag Showcase**: معرض للقطع الأيقونية بدقة عالية وخلفيات استوديو نقية.
- **WhatsApp Direct Checkout**: إمكانية إرسال تفاصيل السلة والطلب مباشرة عبر واتساب بضغطة زر.
- **Cart & Wishlist**: نظام إدارة السلة وقائمة الرغبات محلياً.

## Quick Start
افتح ملف `index.html` في أي متصفح، أو شغّل خادم محلي:
```bash
python -m http.server 8080
```
ثم افتح: `http://localhost:8080/`
